# Visu Trail

Application React permettant de visualiser et planifier des entraînements de trail.

## Installation

Clone le dépôt : https://github.com/Theo9100/Visu--Trail

git clone 

Installe les dépendances :

npm install

Lance l'application :

npm start

## Structure

- `src/` : Code source React
- `public/` : Fichiers statiques (index.html, manifest, logos)
- `package.json` : Configuration du projet
- `.gitignore` : Fichiers ignorés par Git

## Fonctionnalités

- Ajout d'entraînements
- Liste des séances
- Visualisation graphique
- PWA (installation possible sur mobile)
